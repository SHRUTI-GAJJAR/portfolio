## 💻 Run Locally

### 1. Clone the repository

git clone https://github.com/SHRUTI-GAJJAR/portfolio

### 2. Navigate to the project directory

cd shruti-portfolio

### 3. Install dependencies

npm install

### 4. Start the development server

npm run dev

The portfolio will be available on the local development URL provided by Vite.

## 📦 Build for Production

npm run build

### Preview the production build

npm run preview
